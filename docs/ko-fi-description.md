Jobo CPE2 / CPE2+ Replacement Knobs — 3D-printable, multicolour

Replacement control knobs for Jobo CPE2 and CPE2+ film processors (and other Jobo units that use the same knob shaft). Lost or cracked the original? Print a new one in an afternoon.

WHAT YOU GET
• 3 face designs, all on the same knob body (Ø33 × 16 mm):
  – Temperature scale: red zero dot, long and short ticks and − / + at the ends
  – Positions: red dot with "1" and "2"
  – Pointer: red dot with an indicator line
• STEP files, ready for the slicer:
  – blank knob (no markings)
  – one file per design, with the colour inserts as separate named parts
  – full assembly with every part, including the retaining ring
• DXF and SVG files for laser engraving the markings onto a plain knob (mm, 1:1, centred on the knob, with an alignment outline)

HOW IT FITS
The knob has a split hub with a D-shaped bore. A standard 15 mm internal circlip (DIN 472-15) snaps into the groove on the hub and works as a spring: it clamps the hub onto the shaft, so the knob sits firmly without glue and can still be pulled off.
You need one DIN 472 15 mm circlip, found in any cheap circlip assortment.

PRINT SETTINGS (tested workflow)
• Material: PETG or ASA recommended (warm water and chemicals). PLA works but softens sooner.
• Orientation: print upside down, top face on the plate. No supports needed.
• Layer height: 0.2 mm, first layer also 0.2 mm. The colour inserts are exactly one layer thick, so the first layer must be 0.2 mm.
• Walls: 3–4. Infill: 25–40 % gyroid.
• Plate: textured PEI gives a nice matte top; smooth PEI gives a glossy one.
• Multicolour needs an AMS / MMU (or another multi-material setup). Printing in one colour? Use the blank knob and laser-engrave or paint-fill the markings with the DXF or SVG files.

ADDING IT TO BAMBU STUDIO / ORCASLICER
1. File → Import → Import 3MF/STL/STEP… and pick the design you want, e.g. jobo-knob-dot-scale.step.
2. When asked "Load these files as a single object with multiple parts?", click Yes.
3. Flip it: select the object, press F (Lay on face) and click the top face, or rotate 180° around X.
4. In the object list, expand the object. Right-click each "Modifier …" part → Change type → Modifier.
5. Set filaments in the Filament column: Knob = base colour, Modifier Dot = red, the other modifiers = marking colour (e.g. white).
6. Check the settings above (0.2 mm first layer!), slice, and look at layer 1 in the preview. The markings should appear in their colours.

ASSEMBLY
1. Open the circlip slightly with circlip pliers (in the lug holes).
2. Slide it onto the hub from below, lugs into the two slots next to the split.
3. Push until it snaps into the groove.
4. Press the knob onto the shaft, lining up the flat of the D.
